# 决策记录 0002：Engine 原生工具与产品共享工具保持分属

* 状态：Accepted
* 类型：Architecture
* 决策简述：Engine 原生工具由 Engine 管理，产品共享工具由 AnyAgent 产品层管理，并通过 Adapter 连接两侧，同时保持归属与权限边界。
* 当前修订：2026-09-22

## 当前决定

AgentEngine 管理自身的推理循环、上下文、原生工具和私有运行状态；产品层管理产品共享工具，以及共享的 Workspace、Browser、MCP 和 Permissions 能力。产品共享工具可以被多个 Engine 复用。

Adapter 连接 Engine 原生能力与产品共享能力，并映射到具体 Engine 支持的接口；连接不改变任一能力的归属，也不绕过 Engine 或 host 的权限边界。共同契约表达事件和能力声明，保留实际能力差异。

## 理由

Engine 需要保留自己的运行循环、私有上下文和原生工具语义，产品层则需要提供跨 Engine 可复用的共享体验。

分属和 Adapter 连接可以同时保留能力差异与产品复用，并让执行和授权责任保持可追踪。代价是不同 Engine 不能被假设为具有同一组工具能力，这一取舍由共同契约表达。

## 不采用

- 不让某一个 Engine 统领其他 Engine 的原生工具或私有运行状态。
- 不把所有 Engine 原生工具搬到产品核心，只为获得表面上的统一入口。
- 不把所有 Engine 的能力降成一组最低共同能力。
- 不允许 Adapter 通过映射隐藏实际能力差异或绕过权限边界。
